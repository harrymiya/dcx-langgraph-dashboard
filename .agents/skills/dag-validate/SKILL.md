# dag-validate：快速测试

每轮只验证当前实现，不做 DAG 全局审计或证据调查。

1. 优先运行任务 `data.targeted_tests` 中与本轮改动直接相关、当前环境可执行的自动化检查；若没有可用命令，运行最贴近改动的现有测试或构建检查。
2. 只有实际运行并通过的检查才记为通过。记录简短命令和结果；不要求截图、额外报告、制品或外部环境证明。
3. 相关检查通过后将任务标记 `code-ready` 并关闭，供人后续复测和验收。
4. 检查失败就修复并重跑；环境缺失导致无法验证时，如实记录限制。没有通过的相关检查不得标记 `code-ready`。

真实健康数据、支付、消息发送、生产发布和外部系统写入仍须遵守项目授权与安全门禁；本规则只简化普通开发任务的测试和关闭流程。
