# dag-record：关闭当前任务

实现完成且本任务直接相关的自动化测试通过后，立即关闭当前 DAG 任务。

- 在运行时任务快照中把当前任务状态设为 `code-ready`。`code-ready` 表示开发任务关闭，后续由人复测和验收。
- 只回写简短摘要、实际运行的测试命令/结果和循环自动生成的报告路径（如使用 API）。不要收集截图、外部证据、生产证明或额外制品。
- 不修改任务 `id`、`deps` 或基线 `backend/tasks.json`。不要求 commit。
- 相关自动化测试失败时修复并重跑；确实无法继续时标记 `blocked`，附必要的失败命令和原因。
- 本轮输出 3 行以内：完成的任务、改动摘要、测试结果。不要追加逐项验收或 DAG 全局审计。
